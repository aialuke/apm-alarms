# APM Alarms (apm-alarms)

A quick-reference website for a smoke alarm technician, saved to the iPhone home screen.

Which document decides what:

- `docs/product-brief.md` is the master. What the app is, the words, the rules and what is left for later.
- `_data/topic_map.yml` and `_data/brands.yml` decide which brands, units and topics appear.
- `_instructions/` holds the words. A file there is what has been written.
- `DESIGN.md` is the look only.
- `PRODUCT.md` is a short summary for tools. `AGENTS.md` is notes for AI agents.
