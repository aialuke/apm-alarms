Slide the switch on the back to the on position if the lights have not already run through and gone off.

Press and hold House Code on the back until all parts light up blue, then let go. The parts flash quickly for a moment.

Put every other radio alarm into pairing where it is installed. The presses for those alarms are not written yet.

Check that all parts on the remote are flashing blue. The number of flashes equals the number of radio alarms and this remote. The full count can take up to <span class="figure">10</span> minutes. The pattern repeats every <span class="figure">5</span> to <span class="figure">10</span> seconds.

Walk the house and check that the other units flash the same count.

To leave, press House Code and let go when all the parts light up blue. The blue light goes off. The remote can take <span class="figure">5</span> to <span class="figure">20</span> seconds to return to standby.

The units leave pairing by themselves after <span class="figure">30</span> minutes.

<p class="tip">Do not take the tamper pip off until pairing is finished.</p>
