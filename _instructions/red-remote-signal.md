<ul class="signals">
<li>All lights flash once when the battery tab is removed. The remote has turned on.</li>
<li>Solid orange locate light for <span class="figure">150</span> seconds. The remote is the main unit for pairing.</li>
<li><span class="figure">5</span> flashes of the orange locate light. The remote has joined. <a href="{{ '/' | append: page.brand | append: '/' | append: page.unit | append: '/troubleshooting/pairing/' | relative_url }}">Open Pairing</a></li>
<li>Solid green light. Test. The test signal runs for about <span class="figure">150</span> seconds, and the paired alarms sound.</li>
<li>Green light flashes once every <span class="figure">4</span> seconds. Remote battery is low. Report faulty.</li>
<li>Red alarm light and the orange locate light flash quickly. A paired alarm detects smoke.</li>
<li>Orange hush light stays on and the red alarm light stays on. Triggered alarms stay quiet for <span class="figure">10</span> minutes.</li>
<li>All lights go off. No smoke is detected after <span class="figure">48</span> seconds.</li>
<li>Solid orange hush light. A paired alarm's single chirp or double chirp is quiet for <span class="figure">10</span> hours.</li>
<li>Solid orange memory light for <span class="figure">150</span> seconds. Memory check.</li>
<li>No sound from a paired alarm. No past event on the memory check.</li>
<li><span class="figure">1</span> sound. Low battery on the memory check.</li>
<li><span class="figure">2</span> sounds. Fault on the memory check.</li>
<li><span class="figure">3</span> sounds. An alarm was triggered on the memory check.</li>
<li>Orange memory light flashes once every <span class="figure">4</span> seconds for <span class="figure">72</span> hours. A paired alarm has reported a low battery, a fault, or an alarm.</li>
</ul>
