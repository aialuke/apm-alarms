Hold Test for <span class="figure">3</span> seconds. The green light stays on for <span class="figure">150</span> seconds. The paired alarms sound within <span class="figure">60</span> seconds.

Wait more than <span class="figure">25</span> seconds for every alarm.

Press Test once to leave early. The green light goes off.

When a paired alarm detects smoke, the red alarm light and the orange locate light flash. Once the orange hush light is flashing, another press quiets the triggered alarms for <span class="figure">10</span> minutes. The orange hush light stays on and the red alarm light stays on.

If no smoke is found after <span class="figure">48</span> seconds, all the lights go off.

If a paired alarm gives <span class="figure">1</span> chirp or <span class="figure">2</span> chirps, one press of the front button quiets it for <span class="figure">10</span> hours. <span class="figure">1</span> chirp. Low battery. <span class="figure">2</span> chirps. Fault.

Hold Memory D for <span class="figure">3</span> seconds. The orange memory light stays on for <span class="figure">150</span> seconds. Within <span class="figure">25</span> seconds the paired alarms get the history signal.

No chirp. No past event. <span class="figure">1</span> chirp. Low battery. <span class="figure">2</span> chirps. Fault. <span class="figure">3</span> chirps. An alarm was triggered.

Press Memory D once to leave early.

If a paired alarm reports a low battery, a fault, or an alarm, the orange memory light flashes once every <span class="figure">4</span> seconds for <span class="figure">72</span> hours.
