Attach the brackets so the alarms power on.

On the alarm you start with, hold the Network button and count <span class="figure">6</span> to <span class="figure">8</span> flashes of the blue light, then release. The blue light stays on. This mode ends after <span class="figure">9</span> minutes.

On each other alarm, hold the Network button and count <span class="figure">3</span> to <span class="figure">4</span> flashes of the blue light, then release. Fast blue flashes while it searches. Slow blue flashes. Connected. That join also ends after <span class="figure">9</span> minutes.

To finish, hold the Network button on the first alarm and count <span class="figure">2</span> to <span class="figure">3</span> blue flashes, then release. Closing can take <span class="figure">90</span> seconds.

<p class="note tip">Tip. Wait until the first alarm stops flashing before you use the set.</p>
