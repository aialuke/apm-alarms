The button on the cover is printed TEST AND HUSH.

Mount the first alarm, then press that button <span class="figure">2</span> times, quickly.

Mount each other alarm. A new alarm may need the same <span class="figure">2</span> presses to join.

Close with <span class="figure">2</span> presses on the last alarm.

While join mode is open, you get <span class="figure">2</span> soft beeps, the red light flashes <span class="figure">2</span> times quickly every <span class="figure">2</span> seconds, and a sonar ping.

Each alarm that joins makes a Tweedle, then the red light flashes <span class="figure">3</span> times every <span class="figure">2</span> seconds.

Join mode ends after <span class="figure">15</span> minutes.
