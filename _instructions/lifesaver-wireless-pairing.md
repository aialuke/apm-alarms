Mount the first alarm, then press TEST AND HUSH on the cover <span class="figure">2</span> times, quickly.

Mount each other alarm. A new alarm may need the same <span class="figure">2</span> presses to join.

Close with <span class="figure">2</span> presses on the last alarm. The red light turns off on each alarm. Joining has closed.

While join mode is open, <span class="figure">2</span> soft chirps. The red light flashes <span class="figure">2</span> times quickly every <span class="figure">2</span> seconds. A sonar ping.

Each alarm that joins makes a Tweedle. The red light flashes <span class="figure">3</span> times every <span class="figure">2</span> seconds.

Join mode ends after <span class="figure">15</span> minutes.
