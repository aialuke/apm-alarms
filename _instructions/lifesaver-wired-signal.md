<ul class="signals">
<li>Red light flashes every second. During an alarm.</li>
<li>Red light flashes rapidly while the alarm sounds. This alarm started it.</li>
<li>Flashing red light during a false alarm, or just after it. This alarm set the others off.</li>
<li><span class="figure">3</span> long chirps, and the red light stays off. This interconnected alarm did not start the alarm.</li>
<li>Steady green light. Mains power is on.</li>
<li>Green light is off. Mains power is lost.</li>
<li><span class="figure">1</span> red flash about every <span class="figure">5</span> minutes, with no sound. Normal. The self test passed.</li>
<li>Red light flashes once every <span class="figure">10</span> seconds, and no sound. Hush for up to <span class="figure">9</span> minutes. Dense smoke overrides hush and the alarm sounds the whole time.</li>
<li>Red light flashes <span class="figure">3</span> times every <span class="figure">40</span> seconds. After an alarm, this alarm started it.</li>
<li>Quick chirp and red light flash while Test is held on the alarm that started it. Letting go clears the memory. The other alarms only go into a normal test.</li>
<li>Red flash every <span class="figure">5</span> minutes and <span class="figure">1</span> chirp about every <span class="figure">40</span> seconds. Low battery for at least <span class="figure">30</span> days. <a href="#low-battery">View fix →</a></li>
<li>Chirp about every <span class="figure">40</span> seconds, with mains still on. The battery is missing. <a href="#low-battery">View fix →</a></li>
<li>Red flash every <span class="figure">5</span> minutes, and no chirp. Low battery hush for up to <span class="figure">8</span> hours.</li>
<li>Red flash every <span class="figure">5</span> minutes and <span class="figure">3</span> chirps every <span class="figure">40</span> seconds. Chamber fault. Report faulty.</li>
<li>Chirp every <span class="figure">40</span> seconds on the backup battery test. Faulty battery module. Report faulty.</li>
</ul>
