{% include pairing-start.html %}

Before the mount goes on, mark one alarm MASTER and the others SLAVE.

Use a flat-bladed screwdriver to switch the Master and every Slave on.

Press the MASTER Test/Hush button <span class="figure">3</span> times in <span class="figure">2</span> seconds. The network light flashes blue for <span class="figure">30</span> seconds.

While that blue light is on, press the Test/Hush button on each Slave <span class="figure">3</span> times in <span class="figure">2</span> seconds.

The Slave network light flashes red or green for <span class="figure">3</span> seconds. Then both network lights flash green for a further <span class="figure">3</span> seconds.
