On one base, press the wireless test button <span class="figure">3</span> times within <span class="figure">2</span> seconds. The red light stays on for <span class="figure">2</span> minutes.

While that light is on, press the wireless test button on the next base <span class="figure">3</span> times within <span class="figure">2</span> seconds. The light on that base flashes <span class="figure">3</span> times.

Repeat that on every other base. Each one learns to the same first base.

To leave sooner, press the button on the first base <span class="figure">3</span> times within <span class="figure">2</span> seconds.
