# RF fitting research

Source notes for the technician. Brooks and Emerald only. Sources are manuals and official pages opened during this pass. This file is not a page on the phone. Fitting is not in the app.

This note is how the module goes into the alarm, and which way round it goes. It is not a pairing page. The confirmation after pairing is not known. Do not write that the alarm chirps.

A faulty module stays out. Do not diagnose one from these notes.

## Brooks, RF module

**Result.** Found in a manual.

**Model.** EIB3000MRF SmartLINK module. It is sold separately. It fits an EIB3000 series mains alarm. The EIB600MRF leaflet is a different module for EIB600 series battery alarms only. Those lines were not used.

**Source.** Page 8 of https://www.brooks.com.au/index.cfm/_api/render/file/?method=inline&fileID=ED286C0D-B534-48C5-80B5FE58B299EA47. That file is the Owner's Manual linked from https://www.brooks.com.au/data-sheets-manuals/.

**Sheet line.** "being careful to align the pins and keeping them perpendicular to the base as the module is inserted"

**Which way it fits.** Hold the flexible antenna and guide it into the designated hole in the rear of the alarm until about two thirds of its length is in. Then hold the module housing and plug the module into the alarm. Line the pins up. Keep the pins at right angles to the base while the module goes in. The module is fully home when it sits flush with the alarm housing around it. Figure 2c on that page labels the pin line Pin Alignment.

**Manual is silent on.** A front or back mark on the module. A click that means the module is seated.

**Flag.** The sheet also has house coding and a factory reset. Those are not part of fitting the module. The sheet warns that a wired link and a radio link between the same two alarms may cause a continuous alarm loop.

## Emerald, RF module

**Result.** Found in a manual.

**Model.** EP-HYB-RF-MOD. The Hybrid alarm sheet says to add this module so the alarm can interconnect with other Emerald RF smoke alarms. The module leaflet says it fits Hybrid Series smoke alarms. The same leaflet says the module wirelessly interconnects up to 40 Emerald RF alarms. EP-VC-RF-MOD is a different module for 240V series alarms. This note does not use that leaflet.

**Source.** Panel 3 on PDF page 1 of https://emeraldalarms.com.au/wp-content/uploads/2026/01/EP-HYB-RF-MOD-User-Manual.pdf. The PDF did not give selectable text. The lines were read off the page pictures. The Hybrid alarm line that names this module is in https://emeraldalarms.com.au/wp-content/uploads/2024/09/EP-HYB-240-10-User-Manual_2023.11.pdf.

**Sheet line.** "Insert the module into the slot."

**Which way it fits.** The leaflet says to insert the module into the slot. The drawing shows the back of the alarm open. The module goes down into the recess. A green arrow points down. The module picture shows the pins on one end and a white tube standing up from the body. The drawing shows the pin end toward the connector in the alarm.

**Manual is silent on.** A written left or right direction. A picture of a wrong way. A click or a beep for the module entering the slot.

**Flag.** The confirmation after pairing is not known. The leaflet also has a section headed Deactivating wireless connection. That clear is not part of fitting the module.
